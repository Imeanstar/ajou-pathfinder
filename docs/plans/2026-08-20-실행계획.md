> **문서 성격:** 4인 팀(사람이 실행) + Claude(데이터·스캐폴딩 보조) 하이브리드 실행 계획.
> 주제·아키텍처 근거는 [`../주제기획서.md`](../주제기획서.md) 참조 — 이 문서는 "무엇을, 어떤 순서로, 누가"만 다룬다.
> 상태 갱신: 각 태스크 완료 시 `- [ ]`를 `- [x]`로 바꾸고 커밋. Claude는 이 파일 + 메모리로 진행 상태를 계속 추적한다.

**목표:** 2일(8/20 목 ~ 8/21 금) 안에 Must 범위(성적표 파싱→졸업요건 판정→역량진단→로드맵 생성→근거인용) 동작하는 배포본 완성. 8/22~23 주말은 문서·발표 준비.

**마감:** 08/24(월) 10:10 산출물 제출.

## Global Constraints

- 대상 **소프트웨어학과 2025학번**으로 고정 (범위 팽창 방지 — 최우선 결정)
- 에이전트 오케스트레이션은 **LangGraph**로 통일 (`pip install langgraph`). Supervisor + 역량진단·교과추천·비교과추천·로드맵배치 4개 에이전트를 `StateGraph`의 노드로 구성, 상태는 `TypedDict` 기반 그래프 State로 관리(화면4의 세션 State와는 별개 — 대화 컨텍스트는 Task 4-5가 별도 관리)
- 성적표 형식 **아주대 포털 PDF 1종**으로 고정
- 모든 추천은 **closed-set**(수집 DB 안에서만 선택) — LLM이 프로그램·과목을 새로 생성하지 않음
- 졸업요건 **계산은 코드, 판단(대체 가능 여부 등)만 LLM**
- PII(이름·학번)는 **서버 저장 금지**, 마스킹 후에만 LLM 전송
- 공개 데이터 수집 시 **rate limit** 준수, 소량(수백 건) 한정
- 1차 프로젝트 코드 재사용: `../../프로젝트/app/retrieval.py`, `../../프로젝트/app/api.py` 패턴

**원칙: 원본 PDF 이미지는 Gemini에 전송하지 않는다.** 이미지를 보내면 텍스트를 마스킹해도 픽셀에 PII가 남아 무의미해진다. 대신 `pdfplumber`로 텍스트+좌표를 추출(LLM 미사용, 결정론적) → **라벨 기반**으로 PII 위치를 찾아 제거 → 마스킹된 **텍스트**만 Gemini에 전송해 과목 리스트로 구조화한다.

```
PDF 업로드(메모리 처리, 디스크 저장 금지)
  → pdfplumber 텍스트+좌표 추출        [LLM 없음]
  → mask_pii(): 라벨 기반 PII 제거      [LLM 없음]
  → scan_for_leftover_pii(): 잔여 검사  [LLM 없음, 걸리면 fail-closed]
  → 마스킹된 텍스트만 Gemini 전송 → 과목 리스트 JSON
```

4. **실사용자가 실제 브라우저 흐름(업로드→제출→대시보드)으로 발견한 버그**: 검증용 하네스는 `formState`에 `remaining_terms` 필드를 직접 채워 넣고 테스트했지만, `upload.js`의 `handleSubmit()`이 실제로 `sessionStorage`에 저장하는 `formState`(=API 요청 payload 그대로)엔 그 필드가 없음(서버가 기본값을 매겨줄 뿐 응답에 echo되지 않음) — `dashboard.js`가 `FORM_STATE.remaining_terms.length`를 읽다 `undefined` 예외로 죽어서 대시보드 전체가 빈 화면으로 나왔음. 남은 학기 수를 `FORM_STATE.remaining_terms` 대신 항상 존재하는 `PLAN.roadmap.schedule`의 키 개수로 계산하도록 수정. **하네스 기반 검증의 한계**를 보여준 사례 — 하네스가 실제 업스트림 페이지가 만드는 데이터 형태를 정확히 재현하지 못하면 통과해도 실제로는 깨질 수 있다.

**검증 (실측, 2026-08-20):** 백엔드 확장분(메타데이터 패스스루·`requirements_summary`·`citations`·가드레일 토글) 전부 TDD로 먼저 테스트 작성 → 실패 확인 → 구현 → 통과 확인, 테스트 격리 버그 1건(가드레일 오버라이드가 `None`이 아닌 `True`로 남는 문제) 발견 즉시 수정. **최종 전체 테스트 104개 통과**(`pytest -q`). 브라우저 확장 미연결이라(2026-08-20 Task 5-1과 동일한 제약) 클릭 인터랙션 대신: uvicorn 실서버 기동 → 같은 오리진에 임시 테스트 하네스 페이지를 하나 만들어 `POST /api/plan` 실호출 결과를 `sessionStorage`에 그대로 넣고 `dashboard.html`로 리다이렉트 → 헤드리스 Chrome `--dump-dom`으로 렌더링 완료 후 DOM을 캡처해 좌측 현황 카드("6/128", "전공필수 2/10개 이수" 등 실제 API 응답값과 일치)·역량 레이더 SVG(`<polygon>` 2개)·로드맵 학기 라벨(입학년도 기반 "2026-2"~"2028-2" 달력 계산 정확)·챗봇 초기 안내 메시지·가드레일 토글 상태까지 실제 데이터로 채워짐을 확인. `undefined`/`NaN`/`[object Object]` 등 JS 버그 흔적 없음. (`--headless --screenshot` 방식은 이번엔 타임아웃으로 행업 — Task 5-1과 달리 `--dump-dom`으로 대체해 성공. 하네스 파일은 검증 후 삭제, 커밋 대상 아님.) 실제 클릭 인터랙션(챗봇 전송·가드레일 토글 버튼)은 코드 검토로만 확인 — 팀이 실제로 한 번 눌러보길 권장.
